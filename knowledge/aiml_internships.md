# AI/ML Internship Prep for Indian Engineering Students

Target users: 2nd–4th year CSE / AIML / DS students applying to internships.

## What recruiters look for
- Python fluency: pandas, numpy, matplotlib, scikit-learn
- One complete project with problem, dataset, model, evaluation, and demo link
- GitHub with README, not only notebooks
- Basics of SQL and REST APIs
- Communication: explain a project in 90 seconds

## Suggested 6-week plan
Week 1: Python + Git + one Kaggle beginner dataset EDA
Week 2: Supervised learning (regression, classification) and metrics
Week 3: NLP or CV mini-project using a public dataset
Week 4: LangChain / RAG mini-agent and Streamlit UI
Week 5: Resume bullets, LinkedIn, 8–10 internship applications
Week 6: Mock interviews: ML theory + project deep dive

## Common mistakes
- Too many unfinished projects
- No evaluation metrics
- Copy-paste Kaggle notebooks without understanding
- Missing deployed demo or recorded walkthrough
