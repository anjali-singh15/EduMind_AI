# Campus Placement Roadmap (CSE / IT / AIML)

## Typical rounds
1. Online assessment: aptitude + coding
2. Technical interview: DSA + CS fundamentals
3. Managerial / HR round

## DSA focus
- Arrays, strings, hashing, two pointers
- Linked lists, stacks, queues
- Trees and binary search
- Recursion and backtracking basics
- Time complexity explanations

Daily target: 2 problems (1 easy, 1 medium) plus 1 revision of a previous mistake.

## CS fundamentals
- OS: process vs thread, deadlock, scheduling
- DBMS: keys, normalization, joins, indexing, transactions
- CN: OSI vs TCP/IP, HTTP, DNS
- OOPs: encapsulation, inheritance, polymorphism, abstraction

## Resume rule
One page. Every bullet: action + tech + measurable result.
Example: Built a PDF RAG study agent with LangGraph and FAISS; reduced answer hallucination by grounding replies in retrieved chunks.
